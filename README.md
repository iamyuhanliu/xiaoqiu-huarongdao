# 小球华容道

用最少的步数把红球推进黑洞。整个游戏就是一个 `index.html`，用浏览器打开就能玩，不用联网。

## 玩法

- 拖动方块或小球。一次拖动算 1 步，不管滑几格。
- 灰色带 X 的是铁块，不能动。
- **提示**：从当前局面算出下一步最优走法，用虚线框标出目标位置。
- **正确演示**：回到这关开局，按最优解一步步自动走一遍。
- **撤销**（Cmd/Ctrl + Z）和 **重来**。
